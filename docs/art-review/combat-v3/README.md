# ภาพเอฟเฟกต์ต่อสู้ v3 — 17 ตุลาคม 2026

ชุดนี้ใช้ภาพ PNG ที่เจนด้วย built-in image_gen เป็นภาพเอฟเฟกต์หลักทั้งหมด แทนวงแหวน เส้นฟัน ลำแสง และอนุภาคที่เคยวาดด้วยโค้ด ตัวเล่นในเกมมีหน้าที่เลือกภาพ ตัดช่องจากชีต กำหนดตำแหน่ง และเล่นเฟรมเท่านั้น

## ขอบเขตที่ส่งมอบ

- 33 ชีตโปร่งใส ขนาด 1536×1024 พิกเซล ชีตละ 4 ชุด × 6 เฟรม รวม 132 แอนิเมชัน / 792 เฟรม
- 25 โปรไฟล์อาชีพและร่างพิเศษ: อาชีพพื้นฐาน อาชีพขั้นสูงสองระดับ Ranger ที่มีในชุดภาพ และ Darkling
- 64 โปรไฟล์มอนสเตอร์: ศัตรูประจำภูมิภาค บอสโลก บอสดันเจี้ยน Mimic มอนสเตอร์ยึดเมือง และ River Kraken บางตัวมีหลายท่าจึงแยกโปรไฟล์ตามท่าด้วย
- 27 โปรไฟล์เพื่อนร่วมทาง ใช้ภาพท่าประจำตัวตาม sprite key
- 16 ชุดร่วม: ฟัน ทุบ สวนกลับ ป้องกัน เวท 7 ธาตุ ฟื้นฟู อัญเชิญ ระเบิด ลำแสง และหลบหลีก

ผู้เล่นตั้งชื่อและเลือกอาชีพเองได้ จึงจับคู่ภาพผู้เล่นกับอาชีพ/ร่างที่เลือก ส่วนมอนสเตอร์ใช้ชื่อพร้อมชื่อท่า เช่น Nicole สองท่าไม่ปะปนกัน ท่าโจมตีปกติและชาร์จฟันใช้ภาพของเจ้าของเดียวกันด้วยจังหวะและขนาดที่ต่างกัน การป้องกันและสถานะใช้ชุดร่วมที่ระบุไว้ข้างต้น มิได้มีไฟล์แยกทุกท่าย่อยของทุกสกิน

ดูรายชื่อทั้งหมดใน [CATALOG.md](CATALOG.md) และคำสั่งเจน/แหล่งต้นฉบับใน [final-prompts.json](final-prompts.json) ไฟล์ใช้งานอยู่ที่ `public/assets/combat-v3/` ไฟล์ต้นฉบับที่เครื่องมือสร้างและรุ่นที่ไม่ได้เลือกยังคงอยู่ในโฟลเดอร์ generated_images ของ Codex

## การใช้งานในเกม

- การโจมตี เวท ท่าอาชีพ Burst มอนสเตอร์ บอส และ Companion ส่งตัวตนเจ้าของไปยังตัวเล่นภาพเดียวกัน
- แอนิเมชันมีจังหวะเริ่ม รวมพลัง ปลดปล่อย พีก แตกตัว และสลาย เล่นด้วยนาฬิกาเดิม 60 ticks/วินาที และเคารพ hitstop
- เตรียมภาพของคู่ต่อสู้ก่อนเริ่มปะทะ เพื่อลดปัญหาตีครั้งแรกแล้วภาพยังไม่พร้อม เก็บเฉพาะ atlas ที่ใช้ล่าสุดและแคชเฟรมที่มีขอบเขตจำนวน
- ดึงภาพเป็นช่อง 128px แบบ nearest-neighbor แล้วขยายเป็นจำนวนพิกเซลเต็ม ไม่เปลี่ยนสี ไม่วาดทับเป็นรูปทรงใหม่ และไม่ลบเกาะอนุภาคแยกออกจากสไปรต์
- ปรับขนาดให้ภาพสูงอยู่ภายในสนาม รองรับการกลับด้านลำแสงเมื่อโจมตีอีกฝั่ง โหมดลดการเคลื่อนไหวแสดงภาพพีกคงที่พร้อมเฟดแทนการกระพริบหลายเฟรม
- ไม่มีการเปลี่ยนสูตรดาเมจ รางวัล หรือการเชื่อมต่อแมพ

## ตรวจดูภาพ

เปิด `/effects-review.html` แล้วเลือกเจ้าของท่าและประเภทการใช้ภาพ เล่น/หยุดหรือเลื่อนเฟรมได้ หน้าแสดงฉากและโมเดลจากตัวเรนเดอร์เดียวกับเกม และใช้ CombatVFXEngine จริง แต่ไม่สร้างเซฟและไม่ตัดสินผลการต่อสู้

ภาพตัวอย่างอยู่ในโฟลเดอร์นี้ แสดงนักรบ นักบวช บอสมังกร และเพื่อนร่วมทาง ทดสอบความครบของทะเบียน การจับคู่โปรไฟล์ เฟรมไม่ว่าง SHA-256 ของต้นฉบับ การเล่นภาพโดยไม่วาดรูปทรงทดแทน และขอบเขตแคชในชุดทดสอบ โหมดมือถือยังต้องประเมินความเร็วบนอุปกรณ์จริงแยกจากการตรวจขนาดภาพ
