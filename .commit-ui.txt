Rebuild the entire UI as pixel art and strip the glass chrome

Every panel, button, bar, tab, chip, close control and scrollbar in the game was styled with the
same four things: `border-radius: 12px`, `backdrop-filter: blur(12px)`, `box-shadow: 0 8px 32px`
and `transform: translateY(-2px)` on hover. Those four are a modern glass card. The project called
the class `pixel-box`, but no amount of pixel art behind a blurred, rounded, softly-shadowed panel
makes the UI read as pixel art - which is why the game looked like pixel art with a web dashboard
on top of it.

The replacement is one system, built from integer-stepped shading with nothing blurred:

  1. a 2px ink outline        0 0 0 2px
  2. a 2px accent ring        0 0 0 4px        the frame's identity colour
  3. a 2px inset bevel        lit top-left, shaded bottom-right
  4. a hard 4px drop shadow   0 4px 0          no blur radius, no spread

Components: `pixel-box` (and gold/red/darkling/pink variants), `pixel-head`, `pixel-well`,
`pixel-divider`, `pixel-chip`, `pixel-btn` (and six colour variants), `command-card`,
`pixel-bar` + `pixel-bar-fill`, `pixel-tab`, `pixel-close`, `pixel-row`.

Behaviour changes that come with it:

* Buttons press by exactly 3px and their drop shadow shrinks by the same 3px, so a control travels
  one pixel grid step instead of easing upward on hover.
* Stat bars are sunken wells with 6px-segmented fills, so a half-full bar reads as a count rather
  than as a smooth length. The track needs 2px of padding for the well to be visible at all;
  without it the fill starts at the element's own left edge and paints over the bevel.
* Every state change is instant. `transition`, `duration-*` and `ease-*` are gone: a pixel UI snaps.
* Animations step rather than ease and move in whole pixels. `diceSpin` rotated a die by 360
  degrees, which is not a thing pixels can do; it is now a four-step vertical flip.
* The banner entrance is a pure fade. It also scaled from 0.95, which resamples every glyph in it.
* Scrollbars are a square thumb on a sunken track instead of a 2px-rounded grey pill.
* The full-screen "magical bloom" post-process was three `drop-shadow` filters with 2px, 10px and
  22px blur radii - the single softest thing on screen. It is now three zero-blur passes that give
  a 1px/2px/3px chromatic rim while leaving the canvas hard-edged.

Colour variants are two-class selectors (`.pixel-btn.pixel-btn-gold`). A bare class ties with a
Tailwind utility on the same element, and the stylesheet's source order would decide the winner.

`pixel-chip` deliberately sets no background, colour or padding, only a 1px bevel: it is applied
on top of Tailwind colour and spacing utilities, and a component class that set those would win the
specificity tie and flatten every chip to the same dark box.

`scripts/strip_glass_ui.cjs` is the migration that swept the old tokens out of roughly forty
inline class lists, dry-run by default. It is scoped to class-bearing strings, because a whole-file
replace also hits prose: bare `transition` and `shadow` are real Tailwind utilities *and* ordinary
English words, and the terrain painter's comments say "a pixel-art transition rather than a razor
line" and "groundShadow".

`npm run check:css` now also fails the build if any glass utility reaches the built markup, and
checks that all twelve pixel components survived into `dist/index.html`. One rounded blurred panel
is enough to undo the whole effect, so the regression has to be caught automatically.

Also in this change: scripts/README.md and README.md document the art pipeline, and a repo-wide
hazard is written down - a PowerShell `Get-Content | Set-Content` round-trip re-encodes a file and
silently destroys every non-ASCII character. It mangled the Thai text throughout index.html during
this work. Both migration scripts are written in Node for that reason, and the file was restored
from git before the change was redone. The working tree now has no C1 control characters anywhere.

Verification: 129 tests green, typecheck green, 11/11 Tailwind spot checks, 12/12 pixel components
present, 8/8 glass utilities absent. The stylesheet dropped from 41.1 kB to 31.7 kB because the
utilities it no longer uses are simply not generated.
